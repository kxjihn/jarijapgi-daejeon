# 자리잡기 대전

대전 82개 행정동의 실제 공공데이터로 카페를 차리고 1년(12개월) 동안 운영해 보는 게임이에요.
동네와 컨셉을 고르고, 매달 영업시간·가격·직원·홍보를 정하고, 좌석을 늘리거나 신메뉴를 내면서 가게를 키워요.
점수는 입지(40점)와 운영(60점)으로 나뉘고, 사건과 경쟁 가게가 매달 변수가 돼요.

- 파일 하나(`index.html`)로 돌아가요. 서버나 설치가 필요 없어요.
- 휴대폰·패드·컴퓨터 화면을 자동으로 채워요.
- 데이터 출처와 방법은 게임 안의 "데이터 출처" 탭에 있어요.

> 시뮬레이션 수치는 교육용 모델이고, 실제 매출 예측이 아니에요.
